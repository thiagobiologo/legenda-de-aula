# Legenda de Aula

Legenda e tradução ao vivo das aulas (espanhol para português e português para espanhol), **gratuita**, para **Windows + Google Chrome**.

**Guia de instalação passo a passo, com animações, em português e espanhol:**
https://thiagobiologo.github.io/legenda-de-aula/

## Autoria

Criado por **Thiago Silva**, em 30/10/2026, para ajudar os colegas do mestrado e alunos de língua espanhola.

Uso gratuito, pessoal e educacional, mantendo o crédito ao autor. Não é permitido vender este material nem apresentá-lo como se fosse de outra pessoa. Todos os direitos reservados ao autor.

## O que é

- Extensão do Google Chrome com barra lateral: transcreve a aula, traduz e mostra o texto, com os trechos importantes destacados (prazos, trabalhos, avaliações).
- Sentido espanhol para português ou português para espanhol, com barra em português e em espanhol.
- Salva a aula em arquivo `.md`, para estudar depois (por exemplo no NotebookLM).
- Instalador `INSTALAR.bat` em texto aberto (qualquer pessoa pode ler o que ele faz) e `DESINSTALAR.bat`.

## Importante

- O cabo de áudio VB-CABLE é de Vincent Burel (VB-Audio), donationware, e **não** está incluído aqui: o instalador baixa do site oficial (https://vb-audio.com/Cable/).
- O áudio da aula é reconhecido pelo serviço de fala do Google Chrome e a tradução usa o Google Tradutor. O texto salvo fica só no computador de cada pessoa.
- Sem garantia: projeto feito por boa vontade.
